# .github

Organisation-wide configuration for **MIC AIML Build Cycle 2026-27**.

| Path | Purpose |
|---|---|
| `profile/README.md` | The organisation profile shown at <https://github.com/MIC-AIML-Build-Cycle-2026-27> |
| `workflow-templates/` | GitHub Actions starter workflows offered in every repository under **Actions → New workflow** |
| `SECURITY.md` | Default security policy for repositories that do not have their own |

Project repositories carry their own issue templates, PR template and CI. Start new ones from [`project-template`](https://github.com/MIC-AIML-Build-Cycle-2026-27/project-template).
