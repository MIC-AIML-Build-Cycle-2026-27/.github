`6 October 2026 → 30 January 2027`

The Build Cycle is the AIML Department's project cycle. Over four months, student teams design, build, test, evaluate and document real AI, ML and software systems, working the way engineering and research teams do: through issues, pull requests, code review and honest evaluation.

This organisation is the official home of the 2026-27 cycle. Each project has its own repository. Shared guidelines live in the **[Build Cycle Handbook](https://github.com/MIC-AIML-Build-Cycle-2026-27/build-cycle-handbook)**.

## How we work

- **Every project in its own repository**, with its own team, board and two Project Leads who coordinate the work
- **Issues → branches → pull requests → review → CI → merge.** `main` stays working.
- **Measure honestly.** Results come with a method, a baseline and their limitations.
- **Document as we go**, so others can understand, run and build on the work
- **Keep process light.** Structure should help students build, not get in the way of building.
